# Global Instructions

## Communication

When I express a concern about code ("I don't believe this will work"), default to explanation mode:
- Explain the issue and present options
- Wait for explicit authorization before making code changes
- If ambiguous whether I want explanation or action, ask first

## Code Accuracy

Always verify APIs, function signatures, and library usage from authoritative sources:
- Read actual code files, documentation, or error messages
- Use available tools to check implementation details
- Never guess or imagine API parameters, return types, or behavior
- If uncertain, say so and propose how to verify

## Python Environment

When working with Python projects:
- Check if `.venv/bin/activate` exists
- If it exists, ask if I should activate the virtual environment before running Python commands
